# 🚗 DX Hidráulica

Site institucional responsivo desenvolvido para a **DX Hidráulica**, negócio de serviços automotivos localizado em Salvador, Bahia.

O projeto foi desenvolvido de forma voluntária para atender a uma necessidade real: apresentar os serviços e facilitar o contato de clientes por meio do WhatsApp.

## 🌐 Site publicado

**https://dx-hidraulica.pages.dev**

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Cloudflare Pages

## ⚙️ Funcionalidades

- Página institucional responsiva
- Apresentação dos serviços automotivos
- Formulário de solicitação de atendimento
- Validação básica dos campos
- Integração com WhatsApp
- Mensagem personalizada com informações do cliente
- Informações de localização e contato

## 📱 Como funciona o atendimento

1. O cliente acessa o site.
2. Preenche nome, modelo do veículo, problema e telefone.
3. Clica em **Continuar pelo WhatsApp**.
4. O WhatsApp abre uma conversa com a mensagem preenchida.
5. O cliente confirma o envio da mensagem.

O site não utiliza banco de dados nem armazena as informações preenchidas no formulário.

## 🎯 Objetivo do projeto

Desenvolver uma solução digital simples, funcional e acessível para um negócio real, aplicando conhecimentos de desenvolvimento web, responsividade, validação de formulários e integração com serviços externos.
